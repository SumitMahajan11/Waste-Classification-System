# Contributing

Thanks for your interest in improving this project.

## Getting started
1. Fork the repo and clone your fork
2. `pip install -r requirements.txt`
3. Create a branch: `git checkout -b feature/your-change`

## Making changes
- Keep commits focused and use conventional commit messages (`feat:`, `fix:`, `docs:`, `refactor:`)
- Test your changes locally before opening a PR — describe how you tested them in the PR description
- Update the README if you change model performance, dataset structure, or API behavior

## Reporting issues
Open a GitHub issue with steps to reproduce, expected vs. actual behavior, and your environment (OS, Python version).

## Code style
Follow existing formatting conventions in the file you're editing. No strict linter enforced yet — keep it readable.
